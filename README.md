# Morris Hsieh — Personal Website

Personal site for Morris Chun-Mo Hsieh (谢君模), built on the N5 minimal resume template.

**Live URL:** https://morrishsieh3059.github.io

## Sections

- **Home** — Hero with NYC skyline
- **About** — Bio, interests, skills
- **Resume** — Work experience & education (GPA only, no semester grades)
- **NYC** — City life, history, walking routes
- **Travel** — Travel journal entries
- **Dining** — Restaurant picks in NYC & abroad
- **Gallery** — Photo gallery with filters
- **Contact** — Email & social links

## Project structure

The site is authored as one folder per component and assembled into a plain
static site by a small build script — no framework, no runtime dependencies
on GitHub Pages.

```
components/<name>/        one folder per section (home, about, resume, nyc,
                           travel, dining, gallery, contact)
  <name>.html                the section's markup (required)
  <name>.css, <name>.js      section-specific styles/behavior (optional)
  img/                       images this section uses — add new photos here
  data/                      JSON data this section reads (nyc, travel only)
  scripts/                   Python data builders (nyc, travel only)

theme/                     third-party N5 template + UI plugins, unmodified
  css/, js/, fonts/

assets/                    Morris's own shared styles/scripts/images used
  css/, js/, img/          across every section (site chrome, CSS variables)

bootstrap/                 Bootstrap CSS/JS (third-party, unmodified)
vendor/                    Font Awesome + Google Fonts, generated by
                           `npm install` (see scripts/vendor-assets.js) — not
                           committed to git

build/
  template.html            page skeleton with <!--@include:name--> markers
  build.js                 assembles template.html + components/* into dist/

dist/                      generated static site (gitignored) — this is what
                           actually gets deployed; never edit it by hand
```

**Adding a new section:** create `components/<name>/` with a `<name>.html`
partial (and `img/`, `css`, `js`, `data` as needed), add
`<!--@include:<name>-->` to `build/template.html` where it should appear, and
a matching nav link. Run `npm run build` to see it.

**Adding a photo to an existing section:** drop the image into that
section's `img/` folder and reference it from the section's `.html` (or
`.css`) with a path relative to the site root, e.g. `img/<name>/photo.jpg`.

## Local development

```bash
npm install     # also vendors Font Awesome + Google Fonts into vendor/
npm run build   # assembles components/* into dist/
npm start       # builds, then serves dist/ at http://localhost:8000
```

## Deployment

A GitHub Actions workflow (`.github/workflows/deploy.yml`) builds the site
and publishes `dist/` to GitHub Pages on every push to `main`. There's
nothing to build or commit manually.

**One-time setup:** in the repo's Settings → Pages, set "Build and
deployment → Source" to **GitHub Actions** (not "Deploy from a branch").

## Travel data (Google Timeline)

Rebuild travel trips and map from a Google export:

```bash
npm run build-travel -- /path/to/takeout.zip
# or drop export folder:
python3 components/travel/scripts/parse-timeline.py /path/to/Takeout/
```

**Important:** Recent Google Takeout "Timeline" exports often contain only settings (history is on-device). For full visit data, export from the **Google Maps app**:

1. Maps → Profile → **Your Timeline**
2. Settings (gear) → **Export Timeline data**
3. Save the file, then run `npm run build-travel` with that path

Home bases are fixed: **Taipei** (until Aug 1, 2022) and **NYC** (since Aug 2, 2022). A trip starts when you leave base and ends when you return — shown as home pins, not travel destinations.

## Updating content

- **Dining entries:** Edit `components/dining/dining.html`
- **Photos:** Add images to `components/<section>/img/` and reference them from that section's `.html`
- **NYC spots:** Update cards in `components/nyc/nyc.html`
